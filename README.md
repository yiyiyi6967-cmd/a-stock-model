# A股短线模型 V5.9.1

本版不人为抬分，只修正评分权重与重复计分问题。

## 80/20 权重
真实行情/历史统计：
- 量价/K线 30%
- 趋势结构 25%
- 历史统计 25%
合计 80%

辅助：
- 筹码估算 8%
- 消息面 7%
- 风险收益 5%
合计 20%

## 历史25%的处理
历史项继续使用V5.9的：
- 贝叶斯修正
- Wilson 95%区间/保守下限
- 时间顺序70/30样本外验证
- 样本外平均收益
- 胜率可信度

低可信度时历史分向50收缩；样本外负期望会限制历史项，避免趋势/量价重复奖励把历史统计硬抬高。

## 质量分与买入判断分离
综合分用于“股票质量”。
最终是否值得参与仍要求：
- 样本外/保守胜率可靠
- 扣交易摩擦后期望为正
- 盈亏比达标
- 综合质量达标
- 无严重风险闸门

因此，本版不会为了出现70+而制造高分。
