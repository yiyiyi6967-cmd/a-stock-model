# A股短线模型 V7.1 快速周选股版

性能优化：
- 仍只看沪深主板，排除创业板、科创板、北交所、ST。
- 周度初筛仍为最近5交易日累计涨跌 -2%～+2%，这个条件不参与加分。
- 代表池缩小，避免大量串行历史行情请求。
- 5日过滤后最多只让24只进入完整模型，再输出最多Top20。
- 筛选过程增加三阶段进度显示，不再长时间只有转圈。
- 历史行情尽量缓存，Streamlit rerun 时减少重复下载。
- 周内仍只跟踪人工保留下来的股票；删除后不自动补位。
- 保留胜率变化归因与原完整个股分析。

这是针对 Streamlit Community Cloud + 免费行情接口的速度优化版。
