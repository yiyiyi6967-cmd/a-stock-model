# A股短线模型 V6.3

## 趋势模块升级
趋势不再只是均线多空排列，改为趋势状态机：
- 上升趋势
- 上升趋势回踩
- 上升趋势 / 再转强
- 下跌趋势减速
- 底部转强候选
- 下跌趋势延续
- 震荡 / 筑底观察
- 趋势过渡

趋势100分：
- 趋势方向 40
- MA20斜率与加速度 25
- 高低点价格结构 20
- MACD/RSI/短均线确认 15

重点增加：
- MA20下降速度是否减慢
- 趋势加速度
- Higher High / Higher Low
- Lower High / Lower Low
因此“MA20仍向下”不再自动等同于完全没有机会。

## 历史模块继续升级
固定：
- 5日完整路径为主验证窗口
- 3日仅作为启动速度辅助
- TP/SL先后胜率
- 样本外稳定性
- Wilson/Bayesian真实性系统

修正：
历史25分中的“平均收益/交易期望”现在会结合当前计划TP/SL的路径期望，而不只看5日最终收盘平均收益。

本模型输出均为历史统计与技术结构估算，不保证未来收益。
