# A股短线模型 V5.8 — 筹码 + 动态100分评分

核心原则：不为了制造70分而抬分。

总评分目标权重：
- 趋势 25
- 量价 20
- 筹码结构 20
- 历史形态 20
- 消息 10
- 风险收益 5

缺失数据采用“有效权重重新归一化”，不会把缺失项强制记50分。

筹码模型：
- 有历史换手率：换手衰减筹码估算
- 无换手率：成交量加权成本估算
- 主筹码峰
- 估算平均成本
- 70%成本区
- 估算获利盘
- 当前价上方12%范围的筹码压力
- 第一潜在兑现压力区
- 强兑现风险参考区
- 筹码结构评分

注意：
“筹码成本”和“兑现区”均为公开行情统计估算，不代表真实投资者账户成本，也不能证明主力会在某个价格出货。

评分等级：
80-100 强机会
70-79 值得重点关注
60-69 有条件参与
50-59 观察
<50 暂时回避
