# A股短线模型 V5.9 — 胜率真实性系统

新增：
- 原始独立案例胜率
- Beta-Binomial 贝叶斯收缩（20个50/50先验样本）
- Wilson 95%胜率区间
- Wilson保守下限
- 按时间顺序70%早期样本 / 30%后期样本外验证
- 训练期与样本外胜率差异检测
- 样本外平均收益检测
- 胜率可信度 0-100
- 交易期望优先采用足量样本外胜率；样本外不足时使用保守胜率
- 交易期望预留0.15%交易摩擦
- “值得考虑”必须同时通过综合质量、净期望、盈亏比、可信度与样本外门槛

重要说明：
这仍然不能保证未来胜率或盈利。样本外验证是为了降低过拟合风险，而不是证明策略未来一定有效。
当前版本的70/30是时间留出验证，不是完整机器学习walk-forward训练。后续可继续升级为滚动walk-forward。
