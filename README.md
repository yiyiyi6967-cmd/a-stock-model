# A股短线模型 V5.5 — 量价真实性升级

## 本版核心修复
V5.4 的“长下影承接”过于简单：只要下影线占全天振幅超过阈值，就容易显示承接。
V5.5 将“长下影”和“承接”拆开。

### 承接强度 0-100
综合：
- 下影线占全天振幅
- 收盘位于全天振幅的位置
- 当日低点是否接近 MA5/10/20/30/60 或20日低点
- 距离用 ATR 标准化
- 成交量相对20日均量
- 是否巨量下跌
- 是否重新收回开盘/前收附近

输出分级：
- 无明显长下影
- 仅长下影，承接未确认
- 疑似承接
- 强承接

### 量价评分
不再主要依靠固定 +6/-10 分，而使用连续变量：
- 当日涨跌与20日量比配合
- 承接强度
- 上影抛压
- 收盘在全天振幅中的位置

页面会直接显示：
- 20日量比
- 下影占比
- 承接强度
- 支撑距离（ATR）
- 量价具体解释

历史K线形态相似、独立样本去重、交易期望和多源行情校验继续保留。
