# A股短线模型 V6.1

## 首页改版
首页优先显示：
- 最终结论：值得做候选 / 值得观察 / 暂不做
- 股票质量分
- 当前机会分
- 交易可信度
- 建议买入区间
- 第一建议卖出区间
- 第二卖出参考
- 止损/逻辑失效价

只有达到“值得做候选”或“值得观察”时才展示主动买入计划；明显不值得做时不生成主动买入价。

## 详细分析改成按钮式标签页
- 趋势
- 历史相似
- 筹码
- 量价/K线
- 胜率/期望
- 消息
- 全部详情

## 买卖价逻辑
不是固定百分比：
- 买入：支撑、ATR、回踩结构、当前价共同决定
- 卖出：第一/第二压力、模型目标、结构突破位共同决定
- 止损：结构失效位与ATR共同约束

价格是计划区间，不保证盈利。
