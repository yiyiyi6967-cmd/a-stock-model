# A股短线模型 V5.6

## 核心升级：趋势判断透明化

不再只显示“趋势条件不足”。

新增五类阶段：
- 🔴 下跌趋势
- 🟠 止跌观察
- 🟡 筑底/临界（以及震荡/等待）
- 🟢 转强
- 🔵 上升趋势

页面逐项显示：
- 收盘是否站上 MA20
- MA20 是否走平/向上
- MA5 是否拐头
- MA5 是否站上 MA10
- MACD 动能是否非负
- RSI 是否站上 50
- 当前价格距离 MA20 还有多少

## 两级突破
- 第一压力突破观察：突破最近技术压力，代表初步转强
- 结构突破确认：突破20日结构高点/更高压力，确认级别更高

这样不会再出现“第一压力4.94，但只有5.52一个突破确认价”却没有解释的问题。

V5.5 的量价真实性、承接强度，V5.4 的真实K线形态相似与独立样本去重，以及交易期望功能全部保留。
