# A股短线模型 V8.0 — 自选股票池版

核心变化：
- 取消自动扫描全A和周末自动选股。
- 用户批量输入多个6位股票代码，模型只分析自选候选。
- 新增股票时只计算新增股票，不重复计算已有股票。
- 支持删除股票。
- 候选池自动排序并显示Top20；不足20只则全部显示。
- Top20评分用于候选池内部排序：股票质量30% + 当前机会30% + 交易可信度25% + 5日胜率15%。
- Top20评分不替代原模型评分；完整个股分析仍保留原有股票质量、机会、可信度、历史统计和交易计划。
- 每天收盘后可一键“更新全部”，只重新计算当前候选池。
- 保存每日快照，对比5日胜率变化并解释趋势、量价、支撑距离、上下影、机会和可信度等变化。
- 保留原“个股分析”页面。
