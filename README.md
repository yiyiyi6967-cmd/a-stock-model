# A股短线模型 V5.4

核心升级：历史“技术状态相似”改为真正的多日K线形态相似。

## 历史相似比较
默认比较最近15根K线：
- 标准化价格路径
- 每日收益路径
- 成交量路径
- K线实体、上下影
- MA5/MA10/MA20相对位置
- RSI变化
- MACD/ATR标准化动量
- 短期波动率

## 独立样本去重
候选历史案例至少间隔12个交易日，避免同一段连续行情被重复算成多个独立案例。

## 透明输出
- 独立案例数量
- 5日上涨次数 / 总案例数
- 上涨率
- 上涨案例平均收益
- 下跌案例平均亏损
- 5日平均收益
- 25/50/75%收益分位
- 3日摸到+3%、+5%，5日摸到+5%的概率
- 最相似历史案例日期与后续表现
- 形态接近度参考

注意：形态相似与历史统计不保证未来收益。
