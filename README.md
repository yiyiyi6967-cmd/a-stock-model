# A股短线模型 V5.3 — 交易期望模型

新增：
- 可输入模拟本金，默认 10,000 元
- 统计未来5日收涨概率
- 上涨样本平均收益 / 下跌样本平均亏损
- 25%、50%、75%收益分位
- 根据当前买点、目标、止损计算盈亏比
- 计划期望 = 胜率×计划盈利幅度 - 败率×计划亏损幅度
- 折算本金对应的目标盈利、止损亏损、单次统计期望金额
- 自动输出：值得考虑 / 观察 / 不值得做 / 暂不参与
- 样本不足、实时数据冲突、行情陈旧、严重消息风险时限制投资判断

判断门槛：
- 值得考虑：样本>=50、计划期望>=+0.5%、盈亏比>=1.5、综合评分>=68，且数据与消息风险校验通过
- 观察：正期望但优势不足，或样本不足
- 不值得做：计划期望<=0
- 暂不参与：严重消息风险

注意：这是历史相似样本统计模型，不保证未来收益。
