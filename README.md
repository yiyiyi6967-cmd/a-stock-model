# A股短线模型 V5.7 — 承接 + 抛压双向评分

## 上影线不再只是“上影较长”
新增抛压强度 0–100，综合：
- 上影占全天振幅
- 收盘在全天振幅中的位置
- 最高价距离 MA5/10/20/30/60、20/60日高点等压力的 ATR 距离
- 20日量比
- 当前处于20日/60日区间的高低位置
- 阳线/阴线及是否跌回前收
- 低位试盘修正

### 抛压分级
- 无明显长上影
- 普通上影，抛压未确认
- 疑似抛压
- 强抛压
- 高位派发风险
- 低位试盘可能（特殊修正）

## 双向量价
页面同时显示：
- 承接强度
- 抛压强度
- 净量价强度 = 承接 - 抛压
- 支撑/压力 ATR 距离
- 20日/60日区间位置
- 收盘位置
- 后续确认条件

注意：“高位派发风险”是技术形态风险标签，不代表已识别某个主力或确定存在出货行为。
