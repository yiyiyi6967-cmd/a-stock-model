# A股短线模型 V5.2

## 本版解决 V5.1 的 RemoteDisconnected 重点
1. 不再用 `stock_zh_a_spot_em()` 拉取整个 A 股市场实时列表。
2. 实时价格改为单股票请求：
   - 新浪实时行情
   - 腾讯实时行情
3. 两个实时源同时成功时自动交叉验证；价格差异 > 1% 暂停交易分析。
4. 换手率双通道：
   - 东方财富历史换手率字段
   - 新浪实时成交股数 / 流通股本 = 实时估算换手率
5. 实时换手率失败时自动降级到最新历史换手率，不伪造数据。
6. MA60继续参与支撑/压力判断。

## 更新
将压缩包中的 `app.py` 和 `requirements.txt` 覆盖 GitHub 仓库原文件并 Commit。
Streamlit Community Cloud 会自动重新部署，原网址不变。

## 注意
新浪/腾讯/东方财富均为公开网络数据源，不是券商交易接口。接口可能改变或限制云服务器访问。
