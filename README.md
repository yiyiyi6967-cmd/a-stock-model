# A股短线模型 V6.0

核心升级：从“这只股票好不好”进一步拆分为“现在这个价格是不是机会”。

## 三个核心指标
1. 股票质量 0-100
   - 延续V5.9.1的80/20质量体系。
2. 当前价格机会度 0-100
   - 支撑ATR距离
   - 下影承接 / 上影抛压
   - 缩量回踩 / 放量下跌
   - 当前价相对估算平均成本
   - 上方近端筹码压力
   - MA20斜率 / MA5-MA10改善
   - RSI位置
   - 样本外表现
   - 计划盈亏比和统计期望
3. 交易可信度 0-100
   - 样本量
   - Wilson区间
   - 贝叶斯修正
   - 样本外数量与稳定性

## 筹码模块重新解释
不再用“筹码结构12/100”简单暗示不能买。
改成“上方筹码压力0-100”，压力高表示反弹可能遇到解套/兑现卖盘，但不自动否决底部反弹机会。

## 修复
如果历史成本区已经位于当前价格下方，不再错误显示为“第一上方兑现压力区”。

## 交易原则
高质量 ≠ 现在适合买。
低获利盘 ≠ 一定不能买。
便宜 ≠ 一定是机会。
最终“值得考虑”要求当前机会、质量、盈亏比、净期望和统计可信度共同通过。

所有筹码与概率结果均为历史公开行情统计估算，不保证未来收益。
